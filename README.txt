GREENFIELD MODEL SCHOOL - 7 PAGE WEBSITE
========================================

PAGES
1. index.html       Homepage
2. about.html       About, history, headmaster message, administration
3. teachers.html    Mathematics, English and Bangla teacher cards
4. students.html    Best result students, student list, feedback carousel
5. results.html     Search by student ID and department; previous-year summary
6. academics.html   Departments and academic calendar
7. login.html       Breadcrumb and demo login form

HOW TO USE
1. Extract the ZIP file.
2. Keep the assets folder in the same folder as the HTML pages.
3. Open index.html in a browser, or upload the complete folder to your hosting account.
4. Internet is required for Bootstrap CDN, Google Fonts and remote Unsplash photos.

TECHNOLOGY
- HTML5
- CSS3 (assets/css/style.css)
- JavaScript (assets/js/main.js)
- Bootstrap 5.3.3 CDN

IMPORTANT
This is a front-end educational demonstration. Login does not authenticate users,
and result data is sample data stored in JavaScript. A real school system needs
a secure server-side backend, database, password hashing, role permissions and
admin-managed result records. Replace the sample school name, contact details,
teacher/student details, photos and dates with approved real information.
